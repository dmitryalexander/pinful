About Pinful

Pinful is a customized Pinless fork for browsing public Pinterest images and videos, with search groups, collections and a JavaScript wall interface. Pinterest requests use the server connection; external links and Lens open third-party sites directly.

Source: Pinful. Based on Pinless, under the GNU AGPL v3.

FAQ

I want to report abuse

Pinful doesn't host any content - it just proxies what's already publicly available on Pinterest. If something needs to be taken down, please report it directly to Pinterest.

Why cookies?

URLs with tokens end up in your history and server logs. Session cookies are more private in this case.
